## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando. Si escribes menos de 7, borra las líneas que no uses (mínimo 5).

1. Como institución educativa quiero registrar una credencial con identificador único para que quede disponible para validación inmediata sin que se tenga que responder consultas manuales despúes.
2. Como profesional migrante quiero compartir el identificador de mi credencial educativa con quien me lo solicite para que se pueda verificar sin que se tenga que tramitar nada adicional.
3. Como empresa quiero consultar un identificador de credencial y ver en segundos si es auténtica y sigue vigente para acelerar el proceso de contratación de una persona
4. Como empresa quiero saber si una credencial fue revocada y cuándo, para no aceptar un documento que la institución desautorizó o que ya no está vigente.
5. Como profesional migrante quiero  que mis datos personales no queden expuestos públicamente en el registro, para proteger mi privacidad aunque la credencial sea verificable por cualquier empresa.
